# Romantic Travel Scrapbook (Laravel)

## Setup
```bash
composer install
npm install
npm run dev
php artisan migrate --seed
php artisan serve
```

## Modules
- Frontend public pages: home, templates, event landing, trip detail.
- Romantic Travel Scrapbook theme with warm vintage palette.
- Admin dashboard: events/trips CRUD.
- Seeder with 1 template, 1 event and 3 trips.
